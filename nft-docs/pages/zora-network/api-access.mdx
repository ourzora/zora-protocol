# API Access

There are a few supported APIs to access ZORA chain information.

1. RPC Access:

    * Use viem/ethers with the public RPC url (https://rpc.zora.energy/) or [your own node](https://docs.conduit.xyz/guides/run-a-node/op-stack-node) to access information.
    * You can create a [conduit account](https://docs.conduit.xyz/nodes/get-api-keys) to get a free API key for the ZORA network without rate limits on the public node.
    * You can also use [dRPC](https://drpc.org/chainlist/zora) or [QuickNode](https://www.quicknode.com/chains/zora) as paid RPC node providers.
    * If you're looking for dedicated infrastructure, check out QuickNode's [Clusters](https://www.quicknode.com/clusters) offering.
    * [Pinax](https://pinax.network/) provides archive RPC at https://zora.rpc.pinax.network, with full historical state queryable at any block.

2. Block Streaming and Indexing:

    * [Pinax](https://pinax.network/) provides [Firehose](https://app.pinax.network/docs/firehose) at `zora.firehose.pinax.network:443`, which streams full blocks over gRPC including call traces, balance changes and storage changes that a JSON-RPC node does not return.
    * [Substreams](https://app.pinax.network/docs/substreams) at `zora.substreams.pinax.network:443` runs Rust modules in parallel on top of those blocks, writing results to PostgreSQL or ClickHouse, streaming them to a consumer, or feeding a Graph Node as a subgraph data source.

3. Explorer Access:

    Use blockscout APIs to access data:

    * [rest endpoint](https://explorer.zora.energy/api-docs) / [docs](https://docs.blockscout.com/for-users/api/rest-api-endpoints)
    * [graphql endpoint](https://explorer.zora.energy/graphiql) / [docs](https://docs.blockscout.com/for-users/api/graphql) 
    * [rest / etherscan type api endpoint](https://explorer.zora.energy/api) / [docs](https://docs.blockscout.com/for-users/api/rpc-endpoints)
